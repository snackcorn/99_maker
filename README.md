# Maker Studio

브라우저에서 설문·안내문·카드형 콘텐츠를 직접 배치하고 이미지로 내보내는 가벼운 비주얼 메이커입니다. 별도 설치나 서버 없이 `index.html`을 열어 사용할 수 있습니다.

## 주요 기능

- 콘텐츠 요소: 제목/내용, 드롭 선택, 체크 선택, 체크리스트, 목록형, 자유 텍스트
- 배경·꾸미기: 단일 작업 배경, 도형, 다각형, 사진 스티커
- 캔버스 편집: 드래그 이동, 크기 조절, 회전, 투명도, 모서리, 색상, 테두리와 그림자
- 레이어: 드래그 순서 변경, 선택한 레이어 우선 편집, 전체 삭제
- 다각형 편집: 점 추가/제거, 점 이동, 실행 취소/다시 실행, 정다각형, 휠 확대/축소
- 미리보기: 확대/축소, 화면 맞춤, 드래그 분리선으로 영역 크기 변경
- 출력: JPG, PNG, 클립보드 복사, Photoshop에서 열 수 있는 SVG, 작업 JSON
- 기본 프리셋: 게임 성향표, 캐릭터 소개, 체크리스트
- 프로젝트: 전체 상태 JSON 저장·불러오기 및 입력값 포함 여부를 선택하는 공유 링크

## 실행 방법

1. 이 저장소를 내려받거나 복제합니다.
2. [index.html](index.html)을 최신 Chrome 또는 Edge에서 엽니다.
3. 로컬 보안 정책 때문에 클립보드 복사가 제한되면 PNG 내보내기를 사용합니다.

개발용 서버가 필요하면 다음처럼 정적 서버를 사용해도 됩니다.

```bash
npx serve .
```

## 프로젝트 구조

```text
.
├── index.html                 # 화면 구조와 접근성 레이블
├── styles.css                 # 전체 UI·캔버스 스타일
├── app.js                     # 캔버스, 레이어, 인스펙터를 조립하는 핵심 진입점
├── modules/
│   ├── definitions.js         # 1번 요소의 기본 템플릿 데이터
│   ├── format.js              # HTML 이스케이프·색상 변환 유틸리티
│   ├── image-picker.js        # 스티커 및 배경 이미지 파일 선택 처리
│   ├── preview-controls.js    # 미리보기 확대·축소 및 분리선 리사이즈
│   └── export-tools.js        # JPG/PNG/클립보드/SVG 출력 처리
└── 일러스트.png               # 예시 이미지 에셋
```

## 모듈 작성 원칙

- `app.js`는 선택 상태와 캔버스 요소를 관리하고 기능 모듈을 연결합니다.
- 재사용 가능한 기능은 `modules/`에 브라우저용 기능 모듈로 둡니다.
- 모듈은 필요한 콜백만 인자로 받아, 캔버스 전역 상태에 직접 의존하지 않습니다. 로컬 파일 실행을 지원하기 위해 `index.html`에서 순서대로 불러옵니다.
- 새 기능은 가능한 한 `modules/기능명.js`로 추가한 뒤 `app.js`에서 초기화합니다.

## 브라우저 지원

최근 버전의 Chrome·Edge를 기준으로 만들었습니다. 이미지 내보내기와 클립보드 기능은 브라우저 권한의 영향을 받을 수 있습니다.
